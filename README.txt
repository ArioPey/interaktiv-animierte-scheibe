# Interaktiv animierte Scheibe

## Start
Den Ordner auf einen Webserver kopieren und `index.html` öffnen.

## Bedienung
L = ein Bild nach links
R = ein Bild nach rechts
A = automatische Rotation starten/stoppen

## Technik
HTML, CSS und JavaScript. Die Animation verwendet normale <img>-Elemente mit SVG-Einzelbildern.
Kein Canvas und kein WebGL.

## Bildmaterial
Die SVG-Grafiken im Ordner images wurden für diese Aufgabe selbst erstellt.
Es wurden keine externen Bildquellen verwendet.
